## 이번 세션에 완성한 것

### A1 — best.pt OpenVINO 엣지 최적화 → [projects/a1-edge-opt.md](../projects/a1-edge-opt.md)
같은 검출기(YOLO11n, 6클래스)를 OpenVINO INT8 로 양자화.
- **크기 3.2배↓ · mAP −0.46pp** (정확도 손실 사실상 없음)
- 지연은 하드웨어 종속 — 맥 arm64 CPU 에선 INT8 이 오히려 느려지고, **Intel CPU(VNNI)
  2.3배 가속**, Arc B580 은 848→853 fps 포화
- *"INT8 = 항상 빠름"이 틀렸음을 실측으로 보임*
- 코드: [`code/a1-edge-opt/`](../code/a1-edge-opt/)

### A2 — 합성데이터의 sim-to-real 갭 (Arc XPU) → [projects/a2-synthetic-gap.md](../projects/a2-synthetic-gap.md)
합성 학습량을 0.1→1.0 으로 늘리며 스케일링·도메인갭 측정.

| fraction | train imgs | best mAP50-95 | best mAP50 |
|---|---|---|---|
| 0.1 | 239 | 0.865 | 0.938 |
| 0.25 | 597 | 0.899 | 0.964 |
| 0.5 | 1194 | 0.918 | 0.975 |
| 1.0 | 2388 | **0.937** | 0.980 |

- **합성 val 0.94 → 실사 0.42** (도메인갭 절반 이상) — 합성 val 점수가 실사를 크게 과대평가함을 정량화
- 합성 증량은 실사 전이에 계속 값어치(실사 0.28→0.42), 특히 **오검출↓**(precision 0.60→0.76)
- 병목은 recall(0.44 정체) → A2-b 로 확장
- **A2-b 확장(실사 9장 파인튜닝):** recall **0.50→0.67(+0.17)**, precision 0.69→0.79, mAP50-95 0.51→0.59
- 코드: [`code/a2-synth-ablation/`](../code/a2-synth-ablation/)

### 임베디드 시리얼 벤치 — Arduino 실기 3종 → [projects/embedded-serial-bench.md](../projects/embedded-serial-bench.md)
로봇 작업의 세 갈래를 실제 Arduino Uno(ATmega328) 위에서 물리 계층까지 확인·정량화.
- **A 시리얼 하드닝+퍼징** — udp-network-lab 프레이밍(CRC32+시퀀스)을 MCU C 로 포팅,
  손상·재전송 거부 재현(퍼징 800회 오수용 0·hang 없음). HMAC 은 상위 계층 분담을 실측 크기로 논증.
- **B E-STOP 반응지연** — D2↔D4 점퍼, 입력→ISR **9.1 µs**(500/500).
- **C USB-시리얼 링크 특성화** — payload·baud 스윕, RTT 선형·처리량 ~5 KB/s 반이중 병목,
  **~2.5 ms 바닥 = USB-CDC 오버헤드**(라인레이트 아님).
- 커밋 `711efb1`. 코드: [`code/embedded-serial-bench/`](../code/embedded-serial-bench/)

### RoboSec — F1·F2 실기 2차 재현 + 정상 대조군 → [projects/robosec.md](../projects/robosec.md)
2026-09-08 마감 직전 하드웨어가 다시 살아난 8/31, 새 세션에서 F1·F2 를 재현.
- **2차 독립 재현** — 하드웨어 재연결·팔 전원 재인가 등 변동 후에도 위반 1건(nan)이 8/30 과 일치.
  FSM 은 스푸핑된 APPROACH 로 224프레임 전이하고 0.1 속도가 17프레임 누출 — **모델·8/30·8/31 3자 일치**로 결정론 확인.
- **정상 대조군** — 정당한 주행(직진 0.08·제자리회전 0.2·정지, 안전 캡 이내) 60레코드 **위반 0건** →
  사후 회귀 오라클 확보. 첫 캡처의 캡 초과(회전 0.3>0.25)를 스캐너가 즉시 잡아, 베이스 허용(±0.5)과
  안전 불변식(0.25)의 간극을 드러냄.
- 정직한 한계: I1 등 전체미션 불변식은 **그리퍼 서보 하드웨어 고장**(닫힘 무응답)으로 미측정.
