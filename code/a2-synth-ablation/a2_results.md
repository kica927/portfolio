# A2 — 합성데이터 효과 정량화 (실측 로그)

> best.pt 학습에 쓴 Houdini 합성 데이터셋(라벨은 ultralytics 캐시에서 복원)으로
> "합성 몇 장이면 되나 / 합성이 실사에 전이되나"를 측정. 데스크탑 Intel Arc B580 XPU.
> ultralytics 8.4.135 · torch 2.11.0+xpu · yolo11n.pt(COCO)에서 파인튜닝 · 50 epoch.

## A2-a — 합성 스케일링 곡선 (2026-08-31)

학습량을 늘려가며 공통 합성 val 500장에서 mAP 측정.

| 학습 이미지 | fraction | mAP50-95 | mAP50 | 직전 대비 mAP50-95 |
|---|---|---|---|---|
| 239 | 0.1 | 0.8647 | 0.9378 | — |
| 597 | 0.25 | 0.8985 | 0.9640 | +0.034 |
| 1194 | 0.5 | 0.9176 | 0.9747 | +0.019 |
| 2388 | 1.0 | 0.9370 | 0.9802 | +0.019 |

**발견**
- **명확한 수확체감.** 239→597(2.5배)에서 +3.4pp, 그 뒤 2배씩 늘려도 +1.9pp씩. 대략 로그선형.
- **합성 데이터는 (동일 분포에서) 매우 데이터 효율적.** 10%(239장)만으로 이미 mAP50-95 0.865.
- 100% 학습 결과(0.937)는 A1의 원본 best.pt FP32 mAP(0.930)와 일치 — 재현성 확인.

**한계 (중요)**
- 이 곡선은 **합성→합성**이다. "더 많은 합성이 실사 성능도 올리나"는 별개 질문 →
  A2-b(실사 홀드아웃)에서 측정. 동일 분포 수확체감이 실사 전이에도 성립하리란 보장은 없다.

## A2-b — sim-to-real (실사 14장) — 대기 중

- 실사 홀드아웃 14장(첨부 원본 캡처 7 + 기존 test 앞 7) 준비 완료, `real_test.yaml` 세팅.
- best.pt 사전라벨 생성 → **수동 보정 후** 위 4개 모델을 실사에서 평가 예정.
- 사전라벨 단계에서 이미 관찰: 합성 학습 모델이 실사 잡동사니에서 **soccer 대량 환각**
  (KakaoTalk 장면 가짜 soccer 10여 개) → precision 급락으로 정량화될 도메인갭.
- 실행: `a2_eval_real.sh` (합성 val mAP vs 실사 mAP 낙차표).

**정직한 한계:** 실사 14장은 소표본 → 결론은 "예비 신호".

## A2-b — sim-to-real (실사 14장) 완료 (2026-08-31)

합성으로 학습한 A2-a 모델 4개를 **실사 홀드아웃 14장**(첨부 원본 캡처 7 + 기존 test 앞 7,
직접 라벨 보정)에서 평가. GT는 best.pt 사전라벨을 사람이 보정(오버레이로 검증, 42박스).

| 학습 fraction | 합성 val mAP50-95 | **실사 mAP50-95** | 낙차 | 실사 mAP50 | precision | recall |
|---|---|---|---|---|---|---|
| 0.1 | 0.865 | 0.284 | −0.581 | 0.413 | 0.604 | 0.475 |
| 0.25 | 0.899 | 0.304 | −0.595 | 0.457 | 0.576 | 0.489 |
| 0.5 | 0.918 | 0.315 | −0.604 | 0.441 | 0.741 | 0.442 |
| 1.0 | 0.937 | **0.418** | −0.519 | 0.543 | 0.760 | 0.438 |

**발견 (핵심)**
- **거대한 도메인갭.** 합성 val 0.87~0.94 → 실사 0.28~0.42 (mAP50-95). 약 0.52~0.60 하락,
  상대적으로 55~65% 손실. "합성 val 성능"이 실사 성능을 크게 과대평가함을 정량 확인.
- **그러나 합성을 더 넣으면 실사도 오른다.** 실사 mAP50-95가 0.284(10%)→0.418(100%), +0.134.
  A2-a의 합성 수확체감과 달리, 실사에서는 100%까지 꾸준히 개선 → 합성 데이터 증량이
  실사 일반화에 여전히 값어치가 있음.
- **precision이 데이터와 함께 상승**(0.60→0.76): 사전라벨에서 본 "soccer 환각"이 학습량이
  늘수록 줄어듦(오검출 억제). 반면 **recall은 0.44~0.49로 정체** — 실사의 원거리·가림 객체는
  여전히 놓침.

**정직한 한계**
- 실사 14장은 소표본 → **예비 신호**. GT는 사람이 보정했으나 원거리 2장(grab_rgb3·live_rgb)은
  객체가 작아 저신뢰, 잡동사니 KakaoTalk은 우리 클래스 객체만 보수적으로 라벨.
- GT 박스 좌표는 수작업 추정(오버레이로 5장 검증, 명백한 오배치 3건 수정).
- 결론의 방향(큰 갭 + 증량이 실사에 도움 + precision 개선)은 견고하나, 절대 수치는 표본을
  키워 재측정 필요.

## 결론 (A2 전체)
합성 데이터는 (1) 동일 분포에서 수확체감하지만, (2) 실사 전이에서는 증량이 계속 도움되고
특히 오검출을 억제한다. 다만 (3) 합성만으로는 실사에서 mAP50-95 0.42가 상한처럼 보이며,
recall 정체가 병목 → 소량의 실사 파인튜닝이 다음 단계(A2-b 확장).

## A2-b 확장 — 소량 실사 파인튜닝 (2026-08-31)

A2-b에서 병목이던 recall을 실사 소량 파인튜닝이 메우는지 확인. 실사 14장을 층화 분할
(train 9 / test 5, staged·distant·kakao-clean·kakao-clutter 골고루). 합성 최강 모델
(frac_1.0)을 실사 train 9장으로 파인튜닝(80ep, lr0 1e-3)하고 실사 test 5장에서 평가.

| 모델 | mAP50-95 | mAP50 | precision | recall |
|---|---|---|---|---|
| 합성만 (frac_1.0) | 0.514 | 0.637 | 0.693 | 0.500 |
| **+실사 9장 파인튜닝** | **0.586** | 0.681 | **0.794** | **0.667** |
| Δ | +0.072 | +0.045 | +0.101 | **+0.167** |

**발견**
- **실사 9장만으로도 갭이 줄어든다.** mAP50-95 +0.07. 소량 실사가 합성 사전학습 위에서
  효과적.
- **recall이 가장 크게 개선(+0.167).** A2-b에서 지목한 병목(원거리·가림 객체 놓침)을
  소량 실사 파인튜닝이 직접 완화 — "합성으론 못 넘던 벽을 실사 몇 장이 넘긴다".
- precision도 +0.10 — 오검출 추가 억제.

**정직한 한계**
- test가 5장뿐 → 매우 예비적. baseline 절대값(0.514)이 14장 A2-b(0.418)보다 높은 것도
  분할 표본 차이. 유효한 비교는 **같은 5장에서 baseline vs 파인튜닝**의 델타이며, 그 방향
  (특히 recall 개선)은 명확하다. 표본을 키운 재측정이 다음 단계.
